# Code of conduct

AtticDB adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in issues, pull requests and every other project space.
Report conduct problems privately through the [private reporting form](https://github.com/Clawdlinux/atticdb/security/advisories/new). It is the same form as for vulnerabilities.
Maintainers review each report. They may remove content or block people.
